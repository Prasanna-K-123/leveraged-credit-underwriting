Filings must resolve against submissions `recent`, exact accession/form/report end/filing date/primary document; URL must be canonical SEC Archives. Standalone verifier must detect file corruption, manifest changes, missing files and extra files. No async/bypass/retry loops.

Before any live attempt, execute a registered fixture matrix with completely independent fake HTTP response transport to test success, exact bytes, SHA, no overwrite, redirect/403/JSON/cik/missing accession/date/header failures, network failure, reproducibility, corrupt source, and no partial output. Do not treat synthetic fixture success as actual SEC acquisition. If SEC is inaccessible on current runtime, honestly record NOT_RUN; no artificial source hashes.

Release gate for a real SEC Q3 acquisition additionally requires original raw bytes retrievable by this runtime, full SHA readback, verified Companyfacts exact contexts, independent statement table parity, as-of source evaluation and matching-head CI for any GitHub code change. This preflight alone does NOT satisfy the full issuer Q1/Q3 integration gate.
